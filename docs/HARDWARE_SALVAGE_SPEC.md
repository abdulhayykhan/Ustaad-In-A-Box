# Hardware Build Notes

The authoritative parts list is [`BILL_OF_PROVENANCE.md`](BILL_OF_PROVENANCE.md). This file holds build notes only and does not repeat the parts list, so the two cannot contradict each other.

## Build principles
- Reuse existing hardware; no adhesives on boards; everything removable so parts can be returned.
- Run the server on AC power; do not rely on an old internal battery.
- Do not bring a suspect (swollen or leaking) battery near the stand, and never charge one at the booth.

## Battery safety at the booth
This stand has no physical battery containment. A swollen battery should not be handled by visitors. Tell the visitor to put the device on a non-flammable surface away from other things and show the rule on screen. The system gives advice only; it does not physically contain a battery.


## Power
The stand runs from mains power. Power draw was not measured, so no figure is claimed.
